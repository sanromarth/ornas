# Archived Documentation

This directory contains historical engineering documents that explain **why** ORNAS evolved into its current architecture. These are preserved for future contributors who want to understand design decisions.

These documents do **not** describe the current implementation. For the current architecture, see [ARCHITECTURE_FINAL.md](../ARCHITECTURE_FINAL.md).

## Contents

|-----------|----------|
| [wayland/](wayland/) | Wayland clipboard investigation — GTK threading analysis, compatibility matrices, and the decision to use polling |
| [pipeline/](pipeline/) | Pipeline evolution — early designs for the job queue, image worker, dispatcher, and threading model |
| [research/](research/) | Engineering reviews, risk analysis, and roadmap exploration |
| [branding/](branding/) | Icon design exploration and finalist selection process |
