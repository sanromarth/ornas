# Installation

ORNAS is a local-first, offline, privacy-focused clipboard manager. It is available for Linux, Windows, and macOS.

## Platform Support

### Linux
Linux is fully supported. You can download the AppImage or Debian package from the official releases page and install it normally.

### Windows
Windows is supported, but the binaries are currently unsigned. When launching ORNAS, you may see a Microsoft Defender SmartScreen or Smart App Control warning. The warnings are expected because the application is not yet digitally signed. Users should download releases only from the official ORNAS GitHub repository. 

Signed releases are planned through the SignPath Foundation. See [SIGNING.md](../SIGNING.md) for more details.

### macOS
macOS is supported, but the application is currently unsigned and not notarized. When opening the app, you may see an Apple Gatekeeper warning indicating that the developer cannot be verified. This warning appears because the application has not yet gone through Apple's notarization process. 

Notarization is planned for a future release to provide a smoother installation experience. See [SIGNING.md](../SIGNING.md) for more details.

## Downloading ORNAS

Always download the latest version of ORNAS from the [official GitHub Releases page](https://github.com/sanromarth/ornas/releases). Do not download ORNAS from third-party websites.
